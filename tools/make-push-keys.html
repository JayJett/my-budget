Make the notification key

Phone notifications need a signing key, so Apple and Google know the reminders really come from My Budget. This page makes one inside your browser: nothing is sent anywhere, and closing the page forgets it.

1. Make the key

You only need to do this once. Making a new key later switches off notifications on every device until each one turns them on again.

This browser can’t make keys. Try a recent Chrome, Edge, Firefox or Safari.

2. Copy it into Supabase (it’s a secret)

This is a private key. Don’t paste it into a chat, an email, or the app’s code. Only into Supabase, as below.

Copied

  1. Open supabase.com, sign in, and open your project my-budget.
  2. In the left menu, choose Edge Functions, then Secrets (on some screens it’s under Project Settings → Edge Functions).
  3. Add a new secret. Name: VAPID_PRIVATE_KEY. Value: paste the key you just copied.
  4. Press Save. That’s it: there’s nothing to redeploy.

3. Turn notifications on

Open My Budget, tap the bell 🔔, then Reminder settings, and press Turn on for this device. Then try Send a test.
